Project Overview :

The Liyara backend is developed using Node.js and Express.js to handle server-side operations and provide RESTful APIs for the online clothing shopping platform. It manages user-related operations, including registration, login, and profile management. PostgreSQL is used to store user account and authentication data, while JSON Web Token (JWT) authentication supports secure user authentication and authorization. The backend provides communication between the frontend and server-side services to support the platform's functionality.

Features :

User registration and account management
User login and authentication
User profile management
RESTful API development using Express.js
PostgreSQL database integration
JWT-based authentication and authorization
API communication with the frontend

Technologies Used :

Node.js
Express.js
PostgreSQL
